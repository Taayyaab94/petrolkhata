Every stroke is vector-effect="non-scaling-stroke" so the outline stays exactly 1.5px however large the card renders it - the old macro scaled its strokes with the viewBox and went soft and fuzzy on big screens. The 25/50/75% ticks are the actual "define it better" bit: they turn a coloured blob into something you can read a level off at a glance. Draw order matters and is: caps and body FILL first (so the top cap's upper half has a background), then the liquid, then the ticks, then the outline strokes last so nothing paints over the edges. The liquid gets its own bottom ellipse so it fills the rounded base instead of ending in a straight line, and its surface ellipse is stroked so the fill line is a defined edge rather than a blur. The drawn fill is clamped to 0-100 (an over-capacity tank cannot draw liquid outside the cylinder) but the printed percentage is always the TRUE one, so over-capacity stays visible in the label and the title. #} {% macro cylinder(pct, cls) %} {% set clamped = [[pct if pct is not none else 0, 100]|min, 0]|max %} {% set liquid_h = 92 * clamped / 100 %} {% set liquid_y = 112 - liquid_h %} {% endmacro %}
